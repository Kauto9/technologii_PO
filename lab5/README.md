# Лабораторная работа 5. Обработка строк

## Как запустить

```
python normalize.py
python palindrome.py
python replace.py
python variant.py
```

## Результаты проверок

### normalize.py
| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| `  Один   два  ` | `Один два`, слов 2, длина 8 | `Один два`, слов 2, длина 8 |
| `` (пустая) | слов 0, длина 0 | слов 0, длина 0 |

### palindrome.py
| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| `А роза упала на лапу Азора` | Палиндром | Палиндром |
| `а    ` | Палиндром | Палиндром |
| `   ` (пробелы) | Нет текста | Нет текста |
| `Python` | Не палиндром | Не палиндром |

### replace.py
| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| `a::b:` | `a--b-`, замен 3 | `a--b-`, замен 3 |
| `abc` | без изменений, замен 0 | без изменений, замен 0 |

### variant.py (10 — начинается и заканчивается одной буквой)
| Ввод | Совпадения | Количество |
|---|---|---|
| `мама, я. Окно, дом.` | я, окно | 2 |
| `` (пустая) | Нет совпадений | 0 |
| `!!!` | Нет совпадений | 0 |
