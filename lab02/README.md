## Проверки

**time_parts.py**
- 0 -> 0 ч 0 мин 0 с
- 59 -> 0 ч 0 мин 59 с
- 60 -> 0 ч 1 мин 0 с
- 3600 -> 1 ч 0 мин 0 с
- 3671 -> 1 ч 1 мин 11 с

**purchase.py**
- 45, 3, 135 -> стоимость 135, сдача 0
- 45, 0, 100 -> стоимость 0, сдача 100

**variant.py** (бутылки/ящики)
- 0, 10 -> полных 0, остаток 0, всего 0
- 20, 10 -> полных 2, остаток 0, всего 2
- 21, 10 -> полных 2, остаток 1, всего 3
