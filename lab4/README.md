# Лабораторная работа 4. Циклы, счётчики и накопители

## Как запустить

```
python range_numbers.py
python statistics.py
python positive_input.py
python variant.py
```

## Результаты проверок

### range_numbers.py
| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| 2 4 | 2, 3, 4 | 2, 3, 4 |
| 4 2 | 4, 3, 2 | 4, 3, 2 |
| 3 3 | 3 | 3 |

### statistics.py
| Ввод | Сумма | Положительных | Максимум |
|---|---|---|---|
| n=3, -5 -2 -8 | -15 | 0 | -2 |
| n=1, 0 | 0 | 0 | 0 |

### positive_input.py
| Ввод | Квадрат | Отклонено |
|---|---|---|
| 0 -2 3 | 9 | 2 |

### variant.py (10 — Числа не меньше 10)
| Ввод | Количество | Сумма |
|---|---|---|
| n=7, -12 -3 0 2 10 15 20 | 3 | 45 |
| n=0 | 0 | 0 |
