# Лабораторная работа 1

## Как запустить

Открыть папку с проектом в терминале и выполнить:
```
python hello.py
python profile.py
python workload.py
python debug.py
python swap.py
python variant.py
```

## Результаты проверок

**profile.py** — возраст 17, подготовка 10.5 ч/неделю. Результат: через 4 года 21, за 4 недели 42.00, в день 1.50.

**workload.py** — 3 занятия по 90 мин и 2 по 45 мин, доступно 10 часов. Результат: 270 мин и 90 мин, всего 360 мин (6.00 ч), остаток 4.00 ч, за 4 недели 24.00 ч.

**debug.py** — результаты исправленных фрагментов: 5, 18, 7.0.

**swap.py** — аудитории А-101 и Б-202 поменялись местами.

**variant.py** — 3 товара по 12.50, 2 по 20.00, доставка 10.00, внесено 100.00. Результат: 37.50 и 40.00, всего 87.50, сдача 12.50.
