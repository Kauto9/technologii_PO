# Лабораторная работа 6. Списки и обработка наборов данных

## Как запустить

```
python statistics.py
python transform.py
python positions.py
python variant.py
```

## Результаты проверок

### statistics.py
| Ввод | Количество | Сумма | Минимум | Максимум | Среднее |

| -2 0 5 3 | 4 | 6 | -2 | 5 | 1.50 |
| 8 | 1 | 8 | 8 | 8 | 8.00 |
| (пустой) | Нет данных | | | | |

### transform.py
